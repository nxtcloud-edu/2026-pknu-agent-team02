# User Stories

> 페르소나: P1 (일기 작성자 · 나무지기)

---

## US-1: 나무 심을 자리 선택

**As** 일기 작성자,
**I want** 7×7 바둑판 숲에서 빈 칸을 클릭하여 나무를 심을 자리를 고르고 싶다,
**So that** 내가 원하는 위치에 나무를 배치하여 나만의 숲을 꾸밀 수 있다.

### Acceptance Criteria

- [ ] 홈 화면에 7×7 아이소메트릭 격자가 표시된다
- [ ] 빈 칸을 클릭하면 나무 종류 선택 UI가 나타난다
- [ ] 이미 나무가 심어진 칸을 클릭하면 일기장 화면으로 이동한다

---

## US-2: 나무 종류 선택

**As** 일기 작성자,
**I want** 4종류(Ginkgo Tree, Cozy Sakura, Forest Gnome Oak, Celestial Star Tree) 중 원하는 나무를 선택하고 싶다,
**So that** 다양한 나무로 숲을 꾸며 시각적 즐거움을 느낄 수 있다.

### Acceptance Criteria

- [ ] 나무 선택 UI에 4종류가 모두 표시된다
- [ ] 선택 후 해당 칸에 선택한 종류의 나무가 표시된다
- [ ] 나무는 초기 상태(아직 일기 0일)에서 small 크기로 표시된다

---

## US-3: 일기 작성

**As** 일기 작성자,
**I want** 나무를 클릭하면 일주일짜리 일기장이 열리고 날짜별로 일기를 쓰고 싶다,
**So that** 7일 동안의 기록을 차곡차곡 쌓아갈 수 있다.

### Acceptance Criteria

- [ ] 나무 클릭 시 화면이 전환되며 7일분 일기 리스트가 표시된다
- [ ] 일주일은 나무를 심은 날부터 7일이다
- [ ] 작성 전 칸에는 년월일(요일)만 표시된다
- [ ] 날짜 칸을 선택하면 일기 내용을 입력할 수 있다
- [ ] 작성한 일기는 저장 버튼으로 로컬 스토리지에 보존된다

---

## US-4: 나무 성장 확인

**As** 일기 작성자,
**I want** 일기를 쓸 때마다 나무가 자라는 것을 보고 싶다,
**So that** 꾸준히 기록하는 데 대한 성취감을 느낄 수 있다.

### Acceptance Criteria

- [ ] 일기 3일 이하 작성 → small 나무
- [ ] 일기 4~5일 작성 → medium 나무
- [ ] 일기 6~7일 작성 → large 나무
- [ ] 일기를 새로 저장할 때마다 나무 크기가 실시간 갱신된다
- [ ] 홈 숲 화면에서 각 나무의 크기가 정확히 반영된다

---

## US-5: 월별 캘린더 열람

**As** 일기 작성자,
**I want** 홈 화면에서 캘린더 버튼을 눌러 월간 기록을 한눈에 보고 싶다,
**So that** 그동안 쓴 일기를 쉽게 찾아볼 수 있다.

### Acceptance Criteria

- [ ] 홈 화면 좌측 상단에 캘린더 버튼이 있다
- [ ] 버튼 클릭 시 좌측 월간 캘린더 + 우측 일기 리스트 화면으로 전환된다
- [ ] 월 이동(이전/다음 월) 네비게이션이 가능하다

---

## US-6: 감정 기록 및 캘린더 표시

**As** 일기 작성자,
**I want** 일기를 쓸 때 그날의 감정을 선택하고, 캘린더에서 감정 아이콘으로 확인하고 싶다,
**So that** 내 감정 변화를 시각적으로 파악할 수 있다.

### Acceptance Criteria

- [ ] 일기 작성 시 7가지 감정(기쁨, 평온, 슬픔, 화남, 피곤, 설렘, 불안) 중 하나를 선택할 수 있다
- [ ] 캘린더에서 일기가 존재하는 날에 해당 감정 아이콘이 표시된다
- [ ] 우측 일기 리스트에도 감정 아이콘이 함께 표시된다
