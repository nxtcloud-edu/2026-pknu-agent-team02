# User Stories

> 페르소나: 지민 (단일 사용자)
> 기반: `requirements.md` FR-1 ~ FR-13

---

## US-1: 홈에서 나무 성장 확인

**As** 지민  
**I want** 홈 화면에서 현재 키우고 있는 나무의 성장 상태와 Day 진행을 한눈에 확인하고 싶다  
**So that** 오늘 기록해야 할 동기를 얻고 나무가 얼마나 자랐는지 바로 알 수 있다

### Acceptance Criteria

- [ ] 홈 화면 중앙에 현재 Day에 해당하는 나무 이미지가 표시된다
- [ ] "Day N / 7" 형태로 진행 상황이 표시된다
- [ ] "오늘도 마음에 물을 주세요." 안내 문구가 표시된다
- [ ] "오늘 기록하기" 버튼이 제공된다
- [ ] 오늘 기록 완료 시 버튼 대신 완료 상태 메시지가 표시된다

---

## US-2: 달력으로 기록 현황 확인

**As** 지민  
**I want** 달력 위젯을 열어 이번 달에 어떤 날 기록했는지 시각적으로 확인하고 싶다  
**So that** 내 기록 패턴을 한눈에 파악하고 빠진 날을 알 수 있다

### Acceptance Criteria

- [ ] 홈 화면 왼쪽 상단 달력 아이콘을 누르면 달력 뷰가 열린다
- [ ] 기록한 날짜에 감정 대응 아이콘(나무/꽃)이 표시된다
- [ ] 이전/다음 월로 이동할 수 있다
- [ ] "YYYY년 M월 · 일기" 형태로 헤더가 표시된다

---

## US-3: 일기 리스트로 기록 훑어보기

**As** 지민  
**I want** 리스트 위젯을 열어 이번 달 기록을 목록으로 빠르게 확인하고 싶다  
**So that** 특정 날의 기록을 찾아 상세 내용을 볼 수 있다

### Acceptance Criteria

- [ ] 홈 화면 우측 상단 리스트 아이콘을 누르면 일기 리스트가 열린다
- [ ] 리스트에 날짜, 감정 아이콘, Moment 요약이 표시된다
- [ ] 현재 월의 기록만 표시된다

---

## US-4: 4단계 감정 기록

**As** 지민  
**I want** Moment → Emotion → Reason → Insight 순서로 오늘의 감정을 단계별로 기록하고 싶다  
**So that** 하루의 감정을 체계적으로 돌아볼 수 있다

### Acceptance Criteria

- [ ] 한 단계씩 진행하는 UI가 제공된다
- [ ] 상단에 진행 탭(4개)과 현재 단계 번호(N/4)가 표시된다
- [ ] Moment: 텍스트 입력 가능
- [ ] Emotion: 8가지 감정 중 하나 선택 + 강도 1~5 슬라이더
- [ ] Reason: 텍스트 입력 가능
- [ ] Insight: 텍스트 입력 가능
- [ ] "다음" 버튼으로 단계 진행
- [ ] X 버튼으로 취소 후 홈 복귀 가능

---

## US-5: AI 감정 분석 결과 확인

**As** 지민  
**I want** 기록 완료 후 AI가 분석한 오늘의 핵심 감정, 키워드, 메시지를 확인하고 싶다  
**So that** 내가 느낀 감정을 객관적으로 정리하고 자기이해를 높일 수 있다

### Acceptance Criteria

- [ ] 기록 완료 시 "오늘의 정원" 결과 화면이 표시된다
- [ ] 핵심 감정이 이모지 + 텍스트로 크게 표시된다
- [ ] AI 추출 키워드가 해시태그 형태로 표시된다
- [ ] "AI 마음 거울" 섹션에 분석 메시지가 표시된다
- [ ] AI 분석 결과는 영구 저장되어 재열람 시 재분석하지 않는다

---

## US-6: 나무 성장 확인

**As** 지민  
**I want** 기록 완료 후 나무가 한 단계 성장한 모습을 확인하고 싶다  
**So that** 내 기록이 실제로 무언가를 키우고 있다는 성취감을 느낄 수 있다

### Acceptance Criteria

- [ ] 결과 화면에 "Day N → Day N+1" 성장 전환이 표시된다
- [ ] "나무가 한 단계 자랐어요" 메시지가 표시된다
- [ ] "홈으로" 버튼으로 홈 화면 복귀 가능

---

## US-7: 7일 완료 후 나무 수확

**As** 지민  
**I want** 7번째 기록을 완료하면 AI가 내 한 주를 분석해 어떤 나무인지 알려주고 수확하고 싶다  
**So that** 일주일의 감정 여정이 하나의 완성된 결과물로 마무리되는 경험을 할 수 있다

### Acceptance Criteria

- [ ] 7번째 기록 완료 시 "7 DAYS JOURNAL COMPLETED" 특별 화면이 표시된다
- [ ] AI가 8종 나무 중 하나를 결정하여 이름, 이미지, 주간 분석, 키워드를 표시한다
- [ ] "나무 수확하기" 버튼이 제공된다
- [ ] 수확 후 도감에 등록되고 새 사이클(Day 1)이 시작된다

---

## US-8: 나무 도감 수집

**As** 지민  
**I want** 지금까지 수확한 나무들을 도감에서 모아보고 싶다  
**So that** 내 감정 기록의 역사를 수집품으로 관리하고 동기를 유지할 수 있다

### Acceptance Criteria

- [ ] 하단 네비게이션 "도감" 탭에서 도감 페이지 접근 가능
- [ ] 8종 나무가 카드 형태로 표시된다
- [ ] 획득한 카드: 이름, 이미지, 획득 날짜, 횟수(×N)
- [ ] 미획득 카드: "???" + 자물쇠 아이콘
- [ ] 획득한 카드 클릭 시 상세 페이지 이동

---

## US-9: 나무 상세 · 7일 기록 아카이브

**As** 지민  
**I want** 도감에서 완성된 나무를 눌러 그 나무를 키웠던 7일의 감정 기록을 다시 보고 싶다  
**So that** 과거의 감정 여정을 회고하며 자기 성장을 확인할 수 있다

### Acceptance Criteria

- [ ] 상세 페이지에 나무 이름, 영문명, 이미지, 수확일이 표시된다
- [ ] "7일간의 감정 기록" 리스트에 각 날짜별 감정이 표시된다
- [ ] "주간 감정 총평" 섹션에 AI 분석 메시지와 키워드가 표시된다
- [ ] 각 날짜 클릭 시 Moment, Emotion, Reason, Insight, AI 키워드, AI 요약 확인 가능

---

## US-10: 하단 네비게이션

**As** 지민  
**I want** 홈, 기록(달력+리스트), 도감 사이를 하단 네비게이션으로 쉽게 이동하고 싶다  
**So that** 원하는 기능에 빠르게 접근할 수 있다

### Acceptance Criteria

- [ ] 하단에 홈 / 기록 / 도감 3개 탭이 항상 표시된다
- [ ] "기록" 탭은 달력 + 일기 리스트 페이지로 이동한다
- [ ] 현재 활성 탭이 시각적으로 구분된다

---

## US-11: 개발 모드 테스트 기능

**As** 개발자/시연자  
**I want** 개발 모드에서 "다음 날로 이동"과 "테스트 데이터 생성" 기능을 사용하고 싶다  
**So that** 실제 7일을 기다리지 않고도 전체 플로우를 검증할 수 있다

### Acceptance Criteria

- [ ] 개발 모드에서 "다음 날로 이동" 버튼이 제공된다
- [ ] 개발 모드에서 "테스트 데이터 일괄 생성" 기능이 제공된다
- [ ] 프로덕션 빌드에서는 해당 기능이 노출되지 않는다
