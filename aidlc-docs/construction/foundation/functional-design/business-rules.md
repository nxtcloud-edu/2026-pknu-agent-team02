# foundation — Business Rules

## BR-1: 하단 네비게이션 표시

- 하단 네비게이션은 홈(`/`), 기록(`/diary`), 도감(`/collection`) 페이지에서만 표시된다.
- `/record`, `/result`, `/complete` 페이지에서는 하단 네비게이션을 숨긴다.
- 현재 활성 탭은 아이콘/텍스트 색상으로 시각적 구분한다.

## BR-2: 라우팅 가드

- `/record` 페이지는 오늘 기록이 이미 완료된 경우 접근 불가 → 홈으로 리다이렉트한다.
- `/result` 페이지는 방금 기록을 완료한 직후에만 접근 가능하다.
- `/complete` 페이지는 7일째 기록 완료 직후에만 접근 가능하다.

## BR-3: 레이아웃 구성

- 모바일 우선 반응형 (max-width: 480px 기준 최적화).
- 데스크탑에서는 중앙 정렬 컨테이너 (max-width: 430px).
- 모든 페이지의 safe area 고려 (하단 네비 높이만큼 padding-bottom).

## BR-4: 헤더 표시

- 헤더는 네비게이션 포함 페이지에서만 표시된다.
- 홈 헤더: 왼쪽 달력 아이콘 + 중앙 "마음 나무" + 우측 리스트 아이콘
- `/diary`, `/collection` 페이지: 페이지 제목 + 뒤로가기(선택)

## BR-5: 테마 색상

- 배경: 크림/베이지 (#FFF8F0 또는 유사)
- 주요 액센트: 연한 초록 계열
- 텍스트: 브라운/다크브라운 계열
- 카드: 흰색 + 둥근 모서리(border-radius: 16px) + 가벼운 그림자
