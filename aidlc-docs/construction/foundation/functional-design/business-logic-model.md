# foundation — Business Logic Model

## 앱 진입 흐름

1. 사용자가 앱에 접속하면 홈(`/`) 페이지를 표시한다.
2. 활성 TreeCycle이 없으면 자동으로 새 사이클을 생성한다.
3. 모든 페이지에 하단 네비게이션이 표시된다 (기록 플로우/결과 화면 제외).

## 페이지 분류

### 네비게이션 포함 페이지
- `/` (홈)
- `/diary` (기록/달력)
- `/collection` (도감)
- `/collection/:cycleId` (도감 상세)

### 네비게이션 제외 페이지 (전체 화면)
- `/record` (감정 기록 플로우)
- `/result` (오늘의 결과)
- `/complete` (나무 완성)

## 헤더 위젯 동작

- 왼쪽 상단 달력 아이콘: 클릭 시 `/diary` 페이지로 이동
- 우측 상단 리스트 아이콘: 클릭 시 `/diary` 페이지로 이동 (리스트 뷰 활성)
- 헤더 중앙: 서비스명 "마음 나무" 표시
