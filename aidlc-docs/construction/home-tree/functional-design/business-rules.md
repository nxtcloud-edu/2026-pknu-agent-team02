# home-tree — Business Rules

## BR-1: 나무 7단계 성장 이미지

| Day | 단계 | 이모지 | 설명 |
|---|---|---|---|
| 1 | 씨앗 | 🌰 | 씨앗 또는 작은 새싹 |
| 2 | 새싹 | 🌱 | 조금 자란 새싹 |
| 3 | 줄기 | 🪴 | 줄기가 자라기 시작 |
| 4 | 가지 | 🌿 | 작은 가지 생성 |
| 5 | 잎 | ☘️ | 잎이 많아짐 |
| 6 | 거의 완성 | 🌲 | 나무 형태 거의 완성 |
| 7 | 완성 | 🎄 | 최종 나무 완성 |

## BR-2: Day 진행 표시

- "Day N / 7" 형태로 상단에 표시
- 진행 바(progress bar)로 시각적 진행률 표시

## BR-3: 오늘 기록 완료 여부 UI 전환

- 미완료: "오늘 기록하기" 버튼 표시 (초록색, 클릭 시 /record 이동)
- 완료: "오늘의 기록을 완료했어요 🌱" 메시지 표시 (버튼 비활성화)

## BR-4: 사이클 없음 상태

- 활성 사이클이 없으면 Day 0 상태로 표시
- "새로운 나무를 키워보세요" 메시지 + "시작하기" 버튼
- 시작하기 클릭 시 새 TreeCycle 생성 → Day 1

## BR-5: 메시지

- 나무 상단: "오늘도 마음에 물을 주세요."
- 나무 하단: "기록 완료 후 7일차가 되면 가꿔낸 나무를 수확할 수 있습니다."
