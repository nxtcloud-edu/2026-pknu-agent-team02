# 나무 성장 단계 디자인 컨셉

## 공통 규격

- 캔버스: 200×240 px (viewBox="0 0 200 240")
- 스타일: 미니멀 플랫 일러스트, 둥근 형태, 따뜻한 색감
- 배경: 투명 (앱에서 배경색 처리)
- 하단 기준선: y=220 (땅 라인)
- 파일명: `day-1.svg` ~ `day-7.svg`

## 4단계 성장 구조

| Day | 형태 | 높이(대략) | 설명 |
|-----|------|-----------|------|
| 1 | 씨앗 | 20px | 땅 위에 작은 씨앗 하나 |
| 2 | 새싹 | 40px | 씨앗에서 작은 잎 두 장이 올라옴 |
| 3 | 줄기 | 80px | 가느다란 줄기 + 잎 3~4장 |
| 4 | 작은 가지 | 120px | 줄기에서 가지 2개 분기, 잎 증가 |
| 5 | 중간 나무 | 160px | 가지 넓어지고 잎이 풍성해짐 |
| 6 | 거의 완성 | 190px | 나무 형태 완성, 수관(잎 덩어리) 거의 꽉 참 |
| 7 | 완성 나무 | 210px | 각 나무 고유 특징 최대 표현 (꽃, 열매, 색상 등) |

## 디자인 원칙

1. **긍정적 표현** — 어떤 감정이든 나무는 아름답게 완성된다
2. **단계별 차이 명확** — 한 단계 올라갔음을 바로 인지 가능
3. **일관된 성장 패턴** — Day 1~3은 모든 나무가 비슷(씨앗→새싹→줄기), Day 4~7에서 고유 특징 분화
4. **심플한 path** — SVG path 복잡도를 낮춰 로딩 속도 최적화
